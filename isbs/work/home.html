웹 문서 PDF 저장 기능 예시

이 페이지는 브라우저의 기본 인쇄 기능을 활용하여 화면에 보이는 내용을 PDF 파일로 변환합니다.

주요 구성 요소 및 작동 원리

  • window.print() 함수: 브라우저의 인쇄 대화상자를 호출하여 별도의 외부 라이브러리 없이 PDF 저장을 지원합니다.
  • @media print CSS: PDF로 생성될 때 [PDF로 저장하기] 버튼처럼 출력할 필요 없는 요소를 자동으로 숨겨줍니다.
  • 레이아웃 최적화: 여백과 용지 규격에 맞춰 화면 스타일이 자동으로 정돈됩니다.

사용 방법

  1. 상단의 [PDF로 저장하기] 버튼을 클릭합니다.
  2. 인쇄 창이 나타나면 대상을 'PDF로 저장' 또는 'Save as PDF'로 선택합니다.
  3. [저장] 버튼을 눌러 원하는 위치에 PDF 파일을 보관합니다.
