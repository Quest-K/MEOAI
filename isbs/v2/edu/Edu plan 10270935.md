## 3. 결합할인 체험 기능 설계 (R3-1)

### 3-1. 화면 구성
- 위치(안): 1-4 안에 상단 탭 2개 `[직접 해보기]` `[통신사별 결합 안내]`
- 입력
  - 인터넷 속도 선택 (100M, 500M, 1G. LG는 200M 판매 중이나 결합 인터넷 할인표에 없음, 아래 확인 사항 참고)
  - TV 포함 여부 (포함 시 인터넷+TV 결합 할인 반영)
  - 휴대폰 회선 추가·삭제: 현재 통신사(KT/LG/SK/알뜰폰), 월 요금제, 청소년 여부
- 결과: KT, LG, SK 카드를 나란히 노출
  - 카드 상단: 결합 전 인터넷 월 요금, 해당 통신사로 매칭된 회선 수
  - 결합별 줄: ✅ 가능 또는 ❌ 불가, 인터넷 할인, 회선별 할인, 합계 할인액
  - ❌ 불가는 사유를 한 줄로 표시 (예: "77,000원 이상 요금제가 2회선 이상 필요합니다")
  - 통신사별 최대 할인 결합에 "추천" 표시
- 하단 고정 안내: 표시 금액은 예상 금액이며, 실제 적용은 설치 후 고객센터에 신청해야 합니다(3-2 가입 필수 안내와 동일).
