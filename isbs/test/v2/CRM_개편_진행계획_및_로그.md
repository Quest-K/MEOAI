2-7 자동 전환 규칙 세부

| 규칙 | 조건 → 동작 |
|---|---|
| R1 | 상품 개통완료 → 지급제외가 아니면 고객지급 = 지급요청, `opened_at` 기록 |
| R2 | 모든 지급 대상 상품 지급완료 → 상담종료 + 재영업 예약(1년/3년 선택) → 잠재고객 |
| R3 | 지급제외 상품만 있는 고객: 모든 상품 개통완료 → 상담종료 + 개통완료일 기준 재영업 예약 |
| R4 | 지급 대상·지급제외 혼합: 지급 대상 모두 지급완료 + 지급제외 모두 개통완료 → 상담종료, 기준일은 가장 빠른 날짜 |
| R5 | 환수요청 → 상담중 / 환수 입금 확인(환수완료) → 상담종료 |
| R6 | 변경요청 생성 → 상담중 |
| R7 | 예약일이 3개월 이내로 진입 → 고객 구분 가망 + 상담 상태 상담대기 |
| R8 | 상담예약일 입력·변경 → 가망/잠재 자동 분류 |
| R9 | 상담 단계 가입 불가 → 상담종료 + 제외(사유) + 제안 상품 접수불가 자동 처리 |
| R10 | 재인입(상담종료·제외 고객) → 상담중 복귀, 구분은 예약일 기준(없으면 가망), 기존 사유 이력 보존 |
| R11 | 고객부재 연속 3회 → 자동 전환 없이 담당자가 제외(장기부재) 지정 |

### Phase 3. 테스트·검증

| # | 시나리오 | 기대 결과 |

| T13 | 제외·상담종료 고객 재인입 | 상담중 복귀, 기존 사유 이력 보존 |
| T14 | 신규 칼럼이 빈 구 데이터 조회 | legacy 변환 표시, 화면 오류 없음 |
